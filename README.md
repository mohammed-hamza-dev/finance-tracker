# 💰 Finance Tracker

A simple and user-friendly web application for managing personal finances.  
Finance Tracker helps users keep track of their income, expenses, transactions, and overall financial balance.

## 🚀 Live Demo

👉 https://mohammed-hamza-dev.github.io/finance-tracker/

## 📌 Features

- 💵 Add and manage income
- 💸 Add and manage expenses
- 📊 Track total income and expenses
- 💰 Calculate available balance
- 🧾 View transaction records
- 🔍 Search and manage transactions
- 📱 Responsive user interface
- 🔐 User authentication using Firebase
- 📈 Visual representation of financial data

## 🛠️ Technologies Used

- **React.js** – Frontend development
- **JavaScript** – Application logic
- **HTML5** – Structure
- **CSS3** – Styling
- **Firebase** – Authentication and backend services
- **Ant Design** – UI components
- **Charts** – Data visualization
- **Git & GitHub** – Version control and deployment
